# J-MUSIC

A responsive, single-page music discovery website.

## Run locally

Open `index.html` in a browser. The music player uses demo audio, and account/artist forms are UI demonstrations; this static site does not include a backend, authentication, or music uploads.

## GitHub Pages

This repository is configured for a root-level static site. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. Once published, the site will be available at https://onuja070-lang.github.io/J-MUSI/.
